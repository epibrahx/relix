# RELIX 精细化打磨计划（第二轮）

> 前置：MVP Phase 0–7 已完成。
> 本轮目标：让「结构层」在真实数据源、中文环境和大图上都站得住，并补上因「关系推断暂时隐藏」而出现的空缺。
> 文档版本：2026-11-18

## 0. 当前阶段与前提

- 产品形态：连接数据源（SQL DDL / JSON / GraphQL Schema）→ 读取表结构 → 画 ER 图。**只展示声明外键与用户手动创建的关系**。
- **关系推断暂时隐藏**：代码、数据模型字段与测试保留，由默认关闭的开关（`ENABLE_INFERENCE = false`）控制；界面、导出、统计里均不出现推断内容。
- 安全红线不变：只读、只查元数据、不读业务数据行、密码/Token 不落地（仅驻留内存）、不联网上传。
